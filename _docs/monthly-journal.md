# 월간 기록 작성

홈은 `type: monthly`인 공개 글 중 가장 최근 글을 자동으로 보여준다.
전체 월간 기록은 `/monthly/`에서 날짜순으로 조회할 수 있다.

새 글은 `_posts/YYYY-MM-DD-monthly-month.md`에 다음 메타데이터로 작성한다.

```yaml
---
layout: post
title: "YYYY년 M월 기록 — 이번 달을 연결하는 주제"
date: YYYY-MM-DD 12:00:00 +0900
type: monthly
category: monthly
tags: [월간 기록]
permalink: /monthly/YYYY-MM/
description: "홈에 표시할 한두 문장 소개."
excerpt: "홈에 표시할 한두 문장 소개."
---
```

권장 순서는 읽고 정리한 것 → 만드는 과정 → 독서와 일상 → 남은 질문이다.
자료가 없는 항목은 생략한다. 개인 경험과 읽은 날짜를 추정해서 채우지 않는다.
월중 기록이면 기준일을 명시하고, 프로젝트 소개 날짜를 개발 완료 날짜로 바꾸지 않는다.
관련 글은 `relative_url` 필터로 연결한다. 사진은 공개 가능한 실제 사진이 있을 때만 추가한다.

홈의 읽은 책·만든 것·연구와 배움은 공용 아카이브의 분류 규칙을 따라 각각 최신 기록 세 개를 보여준다.
정렬 기준은 게시 날짜이며, 프로젝트 완료일이나 책을 다 읽은 날짜를 뜻하지 않는다.
